### 🤖 Assistant
The Voice Agent has been separated into its own package ([`agent_voice_notifier`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/agent_voice_notifier)) completely decoupled from the Whisper transcription service ([`obs_auto_media`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/obs_auto_media)), with zero weight duplication and automatic standalone fallback.

### What Was Built & Decoupled

1. **Decoupled Conversational Agent**:
   * [`VoiceAgent`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/agent_voice_notifier/src/agent_voice_notifier/companion/voice_agent.py): Holds all wake word detection (`"hey gemini"`, `"computer"`, phonetic variants), continuous conversation windows (30s follow-up), dismissal handling (`"bye"`, `"thanks"`), and Gemini reasoning.
   * Out-of-process echo prevention broadcasts speaking status via UDP so external mic listeners ignore speaker feedback.

2. **Zero-Duplication Shared Whisper & Weights**:
   * [`shared_whisper.py`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/agent_voice_notifier/src/agent_voice_notifier/companion/shared_whisper.py): Discovers already-downloaded model snapshots (`models--mobiuslabsgmbh--faster-whisper-large-v3-turbo`) in `~/.cache/huggingface/hub/` or `obs_auto_media/.cache/`.
   * Enforces `local_files_only=True`—**0 MB duplicate weight downloads**.
   * Reuses shared FFmpeg binaries and CUDA/cuDNN DLLs across sibling environments without package duplication.

3. **Dual-Mode Listener (UDP Packets vs Standalone Fallback)**:
   * [`VoiceAgentListener`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/agent_voice_notifier/src/agent_voice_notifier/companion/listener.py):
     * **Packet Mode (`--mode packet`)**: Listens on UDP `127.0.0.1:8766` for live transcription packets broadcast by [`obs_auto_media`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/obs_auto_media/core/broadcaster.py). Consumes **0% extra CPU and 0 MB extra VRAM** while gaming.
     * **Standalone Fallback Mode (`--mode standalone`)**: Directly captures the microphone via FFmpeg and transcribes using the shared Whisper weights.
     * **Auto Mode (`--mode auto`, Default)**: Listens for external Whisper UDP packets; if no packets are detected, it automatically starts standalone microphone capture. If external packets resume, it pauses local capture to prevent resource contention.

4. **Whisper Broadcaster in `obs_auto_media`**:
   * [`obs_auto_media/core/broadcaster.py`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/obs_auto_media/core/broadcaster.py): Non-blocking fire-and-forget UDP datagrams (`broadcast_whisper_packet`). [`live_cutter.py`](file:///c:/fitxategiak/aplikazioak/_nire_tresnak/obs_auto_media/core/live_cutter.py) no longer requires the voice companion in-process and continues video clipping even if the voice agent is offline.

### How to Run

#### 1. Auto Mode (Listens for packets, falls back to standalone mic)
```powershell
uv run python -m agent_voice_notifier --listen
```

#### 2. Explicit Standalone Mode (Standalone mic + shared Whisper weights)
```powershell
uv run python -m agent_voice_notifier --listen --mode standalone
```

#### 3. Packet-Only Mode (UDP packets from `obs_auto_media` on port 8766)
```powershell
uv run python -m agent_voice_notifier --listen --mode packet --port 8766
```
